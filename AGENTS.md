# Agents Mission Control: agent notes

- Swift package (`Sources/AgentsMissionControl`), built into an app bundle by `build.sh`; no Xcode project. The app has no menu bar item on purpose: some companies block running unknown apps, and everything the person sees lives in the installer (`tools/installer.py`) and the Claude Code plugin (`mod/`).
- Approval is Touch ID in the app (`Privileged.swift#personApproves`). Never move it into the plugin: agents reach `~/.amc/amc.sock` directly.
- Any change to the socket protocol must pass `tests/test-privileged.sh` (and `--touch-id` with a person at the Mac).
- Try installs with a test copy (`AMC_CHANNEL=test`, or `tests/try-install.sh`), never by reinstalling the person's real app.
- If Agent Board's hands off is on (`~/.agent-board/hands-off` exists), do not speak, play sounds or drive input.
